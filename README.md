# QuroERP

QuroERP is an ERP project focused on essential business processes.
The Community edition is being developed first as a free, open-source MVP.

## Community MVP
- Focus on core Materials Management (MM) and Sales and Distribution (SD) processes.
- Keep the initial scope small, practical, and suitable for incremental development.
- Include multilingual support from the start.
- Provide a configurable option to allow negative inventory.

## Technology and Development
- Blazor for the user interface.
- ASP.NET Core and REST APIs for backend services.
- Dapper for data access and PostgreSQL for the database.
- Harness Engineering as the foundation for the development workflow.

## Roadmap
Accounting is planned for the Enterprise edition after the Community MVP.
The project is in its initial development stage; the features above describe its planned scope.
